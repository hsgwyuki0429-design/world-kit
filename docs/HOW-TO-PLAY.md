# 空間ボールゲームの遊び方

スマートフォンで部屋を見回すと、カメラが**実際に観測した**床・壁・台からその部屋専用のステージが
生まれ、そこに置かれたリングへボールを投げ入れるゲームです（Safari Spatial Game v4.0 §2, §58）。

## 必要なもの

- iPhone の Safari（HTTPS で配信されているページ。GitHub Pages のデプロイ先）
- **模様のある床**（ラグ、フローリング、目地のあるタイル、床に置いた物など）。
  つるつるで無地の床は追跡できる点がないので、床として認識されません。
- 2〜3 m 先に、模様のある壁か大きな家具
- 左右に 1 m ほど動ける広さ

## 遊び方

1. 最初の画面の **空間ボールゲームを開く** をタップします。
2. **ゲーム開始** をタップし、カメラと「モーションと画面の向き」へのアクセスを許可します。
   モーションを拒否すると重力の向きが測れないため、床と壁を区別できず、ステージは作られません。
3. 床が画面の下半分に映るようにスマホを少し下に向け、**ゆっくり左右に 1 m ほど動きながら**
   見回します。ときどき**スマホを上下にも傾けて**ください（これで重力の向きが決まります）。
4. 床に緑の枠（GROUND）、壁に青い枠（WALL）が出て、`READY` になると、観測した面の上に
   金色のリングが現れます。リングが画面の外にあるときは、画面の端に出る**金色の矢印**の方へ
   スマホを向けてください。
5. スマホをリングの方へ向け、**画面を長押し**するとパワーがたまります。白い点線が予測軌道です。
   **指を離すと投げます。**
6. リングを通過すると `SUCCESS`。少しすると同じ部屋で次のステージが作られます。

| ボタン | 動作 |
| --- | --- |
| リトライ | 外したあと、ボールをすぐスタート位置に戻します |
| 別のステージ | 同じ部屋で別のステージを生成します |
| 一時停止 | ボールを空中で止めます。もう一度押すと再開 |
| 保存 | 進行（何ステージ目か、成功数）と観測結果を保存します |
| 前回の続きから | 保存した進行から再開します（その回で一度も投げる前だけ） |
| 面の表示 | 観測した面の枠の表示を切り替えます |

## うまくいかないとき

画面下のメッセージが、足りない条件を教えてくれます。

| 表示 | すること |
| --- | --- |
| スマホを上下にも傾けながら見回してください | 左右だけでなく上下にも傾ける |
| 床を映しながら、横に少し動いてください | 床をもっと映して横に動く。模様のある床が必要です |
| トラッキングを見失いました | さっき映していた場所へカメラを戻し、ゆっくり動かす |

## このゲームが「しないこと」

- **観測していない場所に床や壁を作りません。** 観測された床の外へ転がったボールは落ちます。
  見えない壁に当たることもありません（§33）。
- **実際の大きさ（メートル）を仮定しません。** 単眼カメラには縮尺がないため、ボールの大きさや
  重力はすべて「測ったカメラの高さ」を単位にしています（§32）。
- **前回の部屋をそのまま再利用しません。** 保存した部屋の座標は今回のカメラでは照合できないので、
  再開するのは進行だけで、ステージは今観測している部屋から作り直します（§42）。
- **遊んでもフェーズは合格になりません。** 各フェーズの合格判定は、それぞれのフェーズ画面で
  実機・HTTPS・Phase Lock に従って行います（[`docs/phase11/HOW-TO-RUN-DEVICE-TEST.md`](phase11/HOW-TO-RUN-DEVICE-TEST.md)）。
